# ファイルA 照合チェックリスト

## 概要
ファイルA（構造計算書）からAIに抽出させるチェック項目の定義ファイルです。
各項目について「ファイルBのどこの値と一致しているか」を照合します。

---

## プロンプトテンプレート（ファイルA用）

```
以下の技術計算書PDFから、設計に使用した荷重・定数の入力値を抽出してください。
抽出結果はJSON形式で出力してください。

### 抽出対象
- 固定荷重（部位ごとの N/m² 値）
- 積載荷重（用途・種別ごとの N/m² 値）
- 地震関連パラメータ（Co, Z, Rt, Ci など）
- 風荷重パラメータ（Vo, Gf, qp, Cf など）
- 材料強度（降伏点・引張強さ・許容応力度）

### 出力スキーマ
{
  "items": [
    {
      "label": "項目名（日本語）",
      "symbol": "記号（あれば）",
      "value": 数値,
      "unit": "単位",
      "page": ページ番号,
      "bbox": {"x0": 0, "y0": 0, "x1": 0, "y1": 0},
      "context": "前後の文脈テキスト（50文字程度）",
      "source_hint": "計算書に記載されている出典情報（例: 荷重指針 p.45）"
    }
  ]
}
```

## 照合ルール（AIへの指示）

1. **数値の正規化**: カンマ区切り（1,200）と非カンマ（1200）は同一視すること
2. **単位の照合**: N/m² と kN/m² は 1,000 倍の変換で同一視すること
3. **出典ヒント活用**: `source_hint` フィールドにある「p.XX」「表X.X」を優先的に検索に使うこと
4. **信頼度の基準**:
   - 0.95以上: 数値・単位・部位が完全一致
   - 0.80〜0.94: 数値は一致するが単位変換や表現揺れあり
   - 0.80未満: 候補はあるが確認が必要（要目視）
5. **不一致の場合**: `matched: false` とし、最近傍候補と差分を `ai_reasoning` に記載すること
